# Ashish Singh — High-End Scrollytelling Portfolio

An Awwwards-level interactive portfolio website for **Ashish Singh (Data Analyst & Search Quality Specialist)**, powered by **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and a high-performance **HTML5 Canvas image sequence scrubber**.

![Portfolio Preview](/public/sequence/frame_000_delay-0.05s.png)

---

## 🌟 Key Features

- **60 FPS HTML5 Canvas Sequence Scrubbing:** Scrubs through 101 high-resolution portrait animation frames bound to scroll progress via Framer Motion's `useScroll`.
- **Preloading & Zero-Flicker Architecture:** Custom image buffer preloading hook with real-time percentage HUD preventing flashes during scroll.
- **Responsive `object-fit: cover` Rendering:** Dynamically scales to any viewport with `window.devicePixelRatio` retina display optimization.
- **Cinematic Parallax Storytelling:** Staged text overlays that fade in and out at calibrated scroll thresholds.
- **Interactive Case Studies:** Modern glass-morphism cards with deep-dive modal dialogs detailing analytical challenges, solutions, and metrics.
- **Dynamic Capabilities Bento Grid:** Showcasing SQL, Python, Power BI, Excel, Tableau, and Search Quality Evaluation.
- **Delightful Micro-Interactions:** One-click copy for email and phone numbers featuring physics-based confetti bursts.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router, Server Components)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Dark theme aesthetics, glassmorphism)
- **Animation:** Framer Motion (Scroll transforms, springs, modals)
- **Rendering:** HTML5 Canvas API (Hardware-accelerated 2D context)
- **Icons:** Lucide React
- **Micro-effects:** Canvas-confetti

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/portfolio-scrollytelling.git
cd portfolio-scrollytelling
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

### 4. Build for production
```bash
npm run build
npm run start
```
